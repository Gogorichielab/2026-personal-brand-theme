I spent a weekend building a tiny command-line tool to tidy up my notes folder. It renames files by date, moves stray drafts into one place, and prints a short summary when it is done.

The best side projects solve one annoying problem well. This one saves me about five minutes every week, which is exactly enough to feel worth it.
