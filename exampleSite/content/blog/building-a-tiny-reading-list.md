A small static page is sometimes all the software a collection needs.

My reading list began as a collection of tabs. Eventually I could remember why I had saved almost none of them.

I moved the links into a Markdown file with a title and one sentence for each entry. Publishing it as a static page made it easy to share without adding an account system or a database.

## Give each link a job

The sentence beside a link answers one question: why might someone read this? A brief recommendation is more useful than copying the article's subtitle.

The list now grows slowly. Removing an entry is as ordinary as adding one, which helps the collection stay useful.
