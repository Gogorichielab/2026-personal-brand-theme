Help the next person get from curiosity to a working first step.

When I open an unfamiliar repository, I want to know what it does, what I need, and how to try it. A README that answers those questions has already done most of its work.

## Start with the first success

Show the shortest supported path to a useful result. Include the directory where a command should run and describe what success looks like.

For a theme, that might be a demo build followed by a local server. For a library, it might be a small example that uses its main function.

## Keep promises small

An accurate short guide is easier to trust than a long list of possibilities. When a feature is optional, say so. When a step needs a credential, explain where it belongs without including a real value.
